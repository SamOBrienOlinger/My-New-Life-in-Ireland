# Illustrated journey chapters

Generated on 25 October 2026 with the built-in OpenAI image-generation tool for the `ui-ux-engagement-2026-10-25` branch. These are illustrative settings for fictional learning journeys. They do not depict the named characters, an actual service location, an immigration document or an assured outcome.

The existing rural/Dublin hero and character portraits informed the warm ivory, burgundy, teal/sage and ochre art direction. Each chapter was generated separately, inspected, then resized proportionally and encoded as WebP for the website. There is no readable in-image text, so the assets can accompany every supported language. Source PNGs were 1536 × 1024; the shipped WebPs are 1200 × 800.

## Prompt set

Every prompt requested a single 3:2 landscape image, a coherent complete environment rather than a collage, important subjects in the middle horizontal band for a wide chapter crop, natural proportions, calm light, and no text, readable letters, logos, flags, interface elements, watermarks or official approval stamps.
